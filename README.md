# 📖 Buku Tamu Digital Desa Cangkoak

Sistem manajemen basis data pengunjung berbasis web yang dirancang khusus untuk merampingkan dan mempercepat proses administrasi harian di balai desa. Aplikasi ini mendigitalisasi pencatatan buku tamu konvensional (kertas) menjadi sistem pencatatan terpusat yang aman, mudah dilacak, dan terdokumentasi dengan baik.

## 💻 Tech Stack
- **Back-End:** PHP *(Catatan: Ubah menjadi Laravel atau CodeIgniter jika Anda menggunakan framework)*
- **Database:** MySQL
- **Front-End:** Bootstrap, HTML5, CSS3, JavaScript
- **Architecture:** Draw.io & PlantUML (untuk perancangan sistem)

## ✨ Fitur Utama
- **Form Buku Tamu Digital:** Antarmuka responsif bagi tamu untuk mengisi data kunjungan (nama, instansi, tujuan) secara mandiri.
- **Dashboard Admin:** Halaman khusus bagi perangkat desa untuk memantau rekapitulasi data tamu secara *real-time*.
- **Pencarian & Filter Data:** Memudahkan admin dalam mencari riwayat kunjungan spesifik berdasarkan tanggal, nama, atau instansi.
- **Manajemen Autentikasi:** Sistem login yang mengamankan akses data hanya untuk pengurus desa yang berwenang.
